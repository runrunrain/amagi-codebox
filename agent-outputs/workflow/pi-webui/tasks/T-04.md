## 目标（可验收）

在 wails dev（macOS，WKWebView）中验证：TerminalView 的终端区域内嵌 iframe 加载 `http://127.0.0.1:<port>` 本地静态页面，渲染正常、无混合内容/安全拦截、页面内交互（滚动、文本选择、点击）与容器 resize 正常。产出截图证据。

## 实现要求

1. 起一个本地静态测试页 server（python3 -m http.server 或 node 一行 server，端口如 18080；测试页放 worktree 内 `frontend/src/spike/` 下，包含标题、长滚动内容、代码块样式，用 codebox 设计令牌着色展示"纸面"效果即可）。
2. spike 改动最小化：在 TerminalView.vue 的 term-body 内加一个开发条件渲染的 iframe（如 `v-if="spikeWebUI"` 常量 true 或 URL query 开关），src 指向 127.0.0.1 server；不接会话数据、不动 toolbar 逻辑、不进任何路由配置。
3. iframe 属性按蓝图技术方案 §10：不带 allow-same-origin，带 allow-scripts；记录 sandbox 约束下滚动/选择是否仍正常（如异常，测试放宽组合并记录建议）。
4. 验证矩阵：初始渲染/长内容滚动/文本选择/窗口 resize 后 iframe 跟随/热重载不崩/控制台无安全报错（wails dev 输出与页面 console 均记录）。
