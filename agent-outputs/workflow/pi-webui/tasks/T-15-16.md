## T-1.5 目标：internal/webui Go 服务

1. `internal/webui/port.go`：空闲端口分配（listen 0 取端口后关闭→env 注入；竞态窗口按"探测+注册表回退"兜底）。
2. env 注入：在 embedded pi 启动路径为子进程加 `AMAGI_WEBUI_PORT=<port>`（只对 appType=pi；找到 launch spec/env 组装点最小侵入接入；不影响其他 CLI）。
3. `internal/webui/probe.go`：探测状态机 `unknown→probing→available|unavailable`——GET `http://127.0.0.1:<port>/api/info`（503=未就绪继续探测；200 且 sessionId 匹配才 available）；注册表回退扫描（`~/.pi/agent/amagi/webui-registry/` 目录式 per-pid，按 sessionId 匹配+探测验证，契约 §7.3）。
4. `internal/webui/service.go`：Wails 绑定服务（按 bind_list.go 既有模式注册）：`GetWebUIStatus(sessionId)`、`OpenWebPlane(sessionId)→{url}` 等（接口面自行最小设计，前端消费）；会话结束→状态失效。
5. 单测：`internal/webui/*_test.go`（httptest 起 stub /api/info：200 匹配/200 不匹配/503/拒连；端口分配；注册表扫描解析与淘汰）。**不依赖真实 pi 进程**。
